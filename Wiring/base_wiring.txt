# Pit Row Dyno - Wiring Manifest (BASE MODEL)
# Hardware Revision: 1.1 (Divider Update)
# Controller: Sunton ESP32-8048S070
# Scope: RPM & Load Cell ONLY.

## 1. Master Pinout Overview
| ESP32 Pin | Function | Header | Connects To | Notes |
| :--- | :--- | :--- | :--- | :--- |
| **GPIO 11** | **Analog In** | **P2/P3** | **PULLDOWN ONLY** | **3.3kΩ Resistor to GND** (Keeps signal 0V) |
| **GPIO 12** | **Digital In** | **P2** | **RPM Sensor** | **Divider: 2.2kΩ Series / 4.7kΩ Ground** |
| **GPIO 17** | **SCK** (Clock) | **P4** | **Load Cell Amp** | **MUST USE HEADER P4** (Avoids UART Conflict) |
| **GPIO 18** | **DT** (Data) | **P4** | **Load Cell Amp** | **MUST USE HEADER P4** (Avoids UART Conflict) |

## 2. Sensor Connection Details

### A. Load Cell (Force Measurement)
* **Sensor:** HX711 Amplifier Module
* **Location:** HEADER P4 (Do NOT use P3)
* **Wiring:**
    * **HX711 SCK** --> **Pin 17** (Header P4)
    * **HX711 DT** --> **Pin 18** (Header P4)
    * **VCC** --> **5V**
    * **GND** --> **GND**

### B. RPM / Hall Effect Sensor (Voltage Divider)
* **Sensor:** NJK-5002A (PNP Type - 5V Signal)
* **Location:** HEADER P2
* **Components:**
    * **R1 (Inline):** 2.2kΩ Resistor
    * **R2 (Pulldown):** 4.7kΩ Resistor
* **Wiring Path (The "T" Junction):**
    1. **Sensor Black Wire (Signal)** --> **R1 (2.2kΩ)** --> **Pin 12**.
    2. **Pin 12** --> **R2 (4.7kΩ)** --> **GND**.

### C. AFR "Dummy" Termination
* **Wiring:** Solder a **3.3kΩ Resistor** between **Pin 11** and **GND**.
