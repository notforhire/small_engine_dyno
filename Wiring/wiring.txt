# Pit Row Dyno - Wiring Manifest (PRO MODEL)
# Hardware Revision: 1.1 (Divider Update)
# Controller: Sunton ESP32-8048S070
# Scope: Full Suite (RPM, Torque, EGT, Wideband AFR)

## 1. Master Pinout Overview
| ESP32 Pin | Function | Header | Connects To | Notes |
| :--- | :--- | :--- | :--- | :--- |
| **GPIO 11** | **Analog In** | **P2/P3** | **Wideband AFR** | **Divider: 2.2kΩ Series / 3.3kΩ Ground** |
| **GPIO 12** | **Digital In** | **P2** | **RPM Sensor** | **Divider: 2.2kΩ Series / 4.7kΩ Ground** |
| **GPIO 17** | **SCK** (Clock) | **P4** | **Load Cell Amp** | **MUST USE HEADER P4** |
| **GPIO 18** | **DT** (Data) | **P4** | **Load Cell Amp** | **MUST USE HEADER P4** |
| **GPIO 19** | **SDA** (Data) | **P3** | **EGT Amp** | MCP9600 (I2C) |
| **GPIO 20** | **SCL** (Clock) | **P3** | **EGT Amp** | MCP9600 (I2C) |

## 2. Sensor Connection Details

### A. Load Cell (Force Measurement)
* **Header:** P4
* **Pins:** 17 (SCK), 18 (DT)

### B. RPM / Hall Effect Sensor (Voltage Divider)
* **Source:** 5V Hall Signal (PNP)
* **Wiring Path:**
    1. **Sensor Signal** --> **R1 (2.2kΩ)** --> **Pin 12**.
    2. **Pin 12** --> **R2 (4.7kΩ)** --> **GND**.

### C. Wideband AFR Input (Voltage Divider)
* **Source:** 0-5V Analog Signal
* **Wiring Path:**
    1. **AFR Signal** --> **R1 (2.2kΩ)** --> **Pin 11**.
    2. **Pin 11** --> **R2 (3.3kΩ)** --> **GND**.

### D. EGT System
* **Header:** P3
* **Pins:** 19 (SDA), 20 (SCL)
